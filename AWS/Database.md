# AWSデータベース学習記録

## 学習概要
- データウェアハウス (DWH) とRedshift
- RDS, DynamoDB, ElastiCacheの使い分け
- スループットとレイテンシーの違い

## データウェアハウス (DWH) と Redshift
- **DWH**: 分析専用の巨大データベース。
    - 得意：大量データの集計・分析（列指向ストレージ）。
    - 苦手：細かい書き込み・更新。
- **Amazon Redshift**:
    - AWSのDWHサービス。ペタバイト級のデータ分析が可能。
    - **リーダーノード（監督）**: SQLの解析、実行計画の作成、指示出し。
    - **コンピュートノード（作業員）**: 実際の計算とデータ保存。並列処理（人海戦術）で高速化する。

## データベースの使い分け
| サービス | 種類 | 特徴 | 用途 |
| :--- | :--- | :--- | :--- |
| **RDS** | RDB | **整合性重視**。きっちり管理。 | 基幹システム、EC注文、会員情報 |
| **DynamoDB** | NoSQL | **速度・拡張性重視**。サーバーレス。 | ゲーム、IoT、カート、セッション |
| **ElastiCache** | キャッシュ | **超爆速（メモリ）**。一時保存。 | DB負荷軽減、ランキング、セッション |

## パフォーマンス用語
- **スループット**:
    - **「量（Volume）」**。単位時間あたりの処理量。
    - 「土管の太さ」。蛇口から出る水の量。
- **レイテンシー**:
    - **「速さ（Speed）」**。反応速度、遅延。
    - 「待ち時間」。蛇口をひねってから水が出るまでの時間。

## 現時点での理解レベル
- Redshiftは「分析専用の巨大倉庫」で、RDSとは役割が違う。
- リーダーノード＝監督、コンピュートノード＝作業員という構成で並列処理している。
- スループットは「量」、レイテンシーは「速さ」。
